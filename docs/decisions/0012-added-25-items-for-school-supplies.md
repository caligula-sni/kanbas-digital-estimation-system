# ADR 0012: Added 25 more items for School Supplies

## Status
accepted

## Context
Obviously, this is not a very big like minor or major changes but as developer and also in the perspective of the user,
im looking into delivering more information for the user and with that also delivering more items to be included in the system.

## Decision

**School Supplies items from 15 -> 40** 
Added 25 items (ids 87-111): 7 verified via SM Stationery/National Book Store (Pilot, Faber-Castell, Crayola), 18 estimated (Mongol, Panda, Best Buy, Orions, and other common PH stationery brands with no official tracked price).

## Consequences

- School Supplies verified ratio: 14/40 (~35%) — lower than Food's 65%, since stationery isn't DTI/PSA tracked the way food commodities are
- Catalog total: 86 → 111 items
