# ADR 0013: Added 25 more items for Food and Groceries 

## Status
accepted

## Context
Obviously, this is not a very big like minor or major changes but as developer and also in the perspective of the user,
im looking into delivering more information for the user and with that also delivering more items to be included in the system.

## Decision

**Food and Groceries items from 40 > 65** 
More real DTI-tracked categories confirmed (luncheon meat, more sardine/coffee brands, pandesal, more toilet soap SKUs)Added 25 items (ids 87-111): 13 of these 25 are verified, 12 are honest estimates for common brands DTI doesn't track (pasta, hotdogs, mayo, soda, ice cream).

## Consequences
